    ```python
    import os
    import re
    import pathlib
    from adsops.sysscript.mock import MockSys

    _LOAD_PATTERN = re.compile(
        r"""load\(\s*["']([^"']+)["'](?:\s*,\s*["']\w+["'])*\s*\)\n?"""
    )

    class SysscriptRunner:
        def __init__(self, sys_global=None):
            self._sys = sys_global if sys_global is not None else MockSys()

        def _find_sysscripts_root(self, script_path: pathlib.Path) -> pathlib.Path:
            for parent in script_path.parents:
                if parent.name == "sysscripts":
                    return parent
            raise ValueError(f"No 'sysscripts/' ancestor found for: {script_path}")

        def _resolve_load(self, load_path: str, script_dir: pathlib.Path,
                          sysscripts_root: pathlib.Path) -> pathlib.Path:
            resolved = (script_dir / load_path).resolve()
            root = sysscripts_root.resolve()
            if not str(resolved).startswith(str(root) + os.sep) and resolved != root:
                raise ValueError(f"load({load_path!r}): path traversal not allowed")
            return resolved

        def run(self, script_path: str) -> dict:
            path = pathlib.Path(script_path).resolve()
            root = self._find_sysscripts_root(path)
            content = path.read_text()
            globs = {"sys": self._sys}
            for m in _LOAD_PATTERN.finditer(content):
                lib_path = self._resolve_load(m.group(1), path.parent, root)
                lib_src = lib_path.read_text()
                lib_src_clean = _LOAD_PATTERN.sub("", lib_src)
                exec(compile(lib_src_clean, str(lib_path), "exec"), globs)
            main_src = _LOAD_PATTERN.sub("", content)
            exec(compile(main_src, str(path), "exec"), globs)
            return globs
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI input -> runner.py | Script path from user CLI argument (untrusted file path) |
| load() path -> filesystem | Relative paths in .star files resolve to filesystem reads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | runner.py _resolve_load | mitigate | Resolve to absolute path via pathlib.resolve(); check startswith(sysscripts_root + os.sep) OR == root. Rejects ../../../etc/passwd style traversal. Mirrors agent T-03-01. |
| T-04-02 | Tampering | runner.py _resolve_load | mitigate | pathlib.resolve() follows symlinks before comparison — symlink pointing outside sandbox is caught by the startswith check on the resolved absolute path. |
| T-04-03 | Elevation of Privilege | runner.py exec() | accept | Python exec() provides no sandbox. Acceptable: sysscripts authored by ops team, internal tooling only, not exposed to untrusted input. Real agent uses Go sandboxing for production. |
| T-04-04 | Information Disclosure | cli.py error output | mitigate | ValueError and NotImplementedError messages printed to stderr. No stack traces exposed to stdout. Internal paths visible only in error context which is acceptable for internal CLI tool. |
</threat_model>
